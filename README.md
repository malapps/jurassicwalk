# Jurassic Walk

A progressive web app game that encourages walking by letting you discover amber pieces and hatch dinosaurs in the real world.

## Stage 1 - Basic Walking Tracker

Walk around in the real world and see your position on a map with:
- Animated arrow showing your direction
- Trail showing where you've walked
- Distance counter (resets daily)

## How to Play

1. Open the app on your Android phone in Chrome
2. Allow location permissions
3. Start walking! Your position will show on the map
4. The screen will stay awake while you walk
5. Distance resets each day
